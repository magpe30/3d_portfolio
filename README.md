# Magda — Portfolio

Personal portfolio site: a persistent WebGL starfield/nebula backdrop (Three.js
via react-three-fiber + drei) running behind every section, with Framer Motion
scroll-in animations throughout.

## Sections

- **Hero** — animated intro over the 3D scene
- **About**
- **Professional Experience**
- **Personal Projects** — featuring [ride-sd](https://github.com/magpe30/ride-sd)
- **Contact**

## Tech stack

- React + Vite
- Tailwind CSS
- react-three-fiber / drei / three.js
- Framer Motion

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).
